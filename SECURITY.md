# Security Policy

CryoMap is in public beta and maintained on a best-effort basis. Security
reports are still taken seriously — thank you for helping keep users safe.

## Reporting a vulnerability

**Please report security issues privately. Do not open a public GitHub issue,
pull request, or discussion for a suspected vulnerability.**

Email **rajshahbuilds@gmail.com** with:

- a description of the issue and its impact,
- steps to reproduce (a minimal proof of concept helps),
- affected version, commit, or URL.

You can expect an acknowledgement on a best-effort basis. Please give a
reasonable amount of time for a fix before any public disclosure, and avoid
accessing or modifying data that isn't yours while investigating.

If you prefer, you may instead use GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
on this repository (Security → Report a vulnerability).

## Scope

This policy covers the CryoMap source in this repository and the official hosted
beta at https://cryomap.vercel.app. Third-party deployments you run are outside
this policy — their security is the operator's responsibility.

## Supported versions

As a pre-1.0 beta, only the latest release and `main` receive security fixes.
